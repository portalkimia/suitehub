Koneksi Backend Google Apps Script

Karena antarmuka ini di-hosting di GitHub Pages, Anda perlu menghubungkannya ke Web App Google Apps Script backend agar proses AI Gemini dan pembuatan dokumen Drive dapat berjalan otomatis.

help Langkah Singkat Mendapatkan URL Web App:
  1. Buka file Code.gs di Google Apps Script.
  2. Klik tombol biru Deploy (Terapkan) → New deployment.
  3. Pilih tipe Web app.
  4. Set Execute as: Me (email Anda).
  5. Set Who has access: Anyone (Siapa saja) — PENTING untuk akses dari GitHub!
  6. Salin URL Web App dan tempelkan di atas.
