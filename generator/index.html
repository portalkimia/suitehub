Koneksi Backend Google Apps Script

Karena antarmuka ini di-hosting di GitHub Pages, hubungkan ke Web App Google Apps Script backend agar fitur AI Gemini dan pencetakan dokumen Google Drive berjalan mulus.

Disimpan pada browser pribadi guru dan dikirim melalui HTTPS.
help Panduan Singkat Mendapatkan URL Web App:
  1. Buka file Code.gs di Google Apps Script.
  2. Klik tombol biru Deploy (Terapkan) → New deployment.
  3. Pilih tipe Web app.
  4. Set Execute as: Me (email Anda).
  5. Set Who has access: Anyone (Siapa saja) — PENTING!
  6. Di Script Properties, simpan GEMINI_API_KEY.
  7. Jalankan buatTokenAksesGuru_(), salin token dari log eksekusi, lalu tempelkan di atas.
  8. Salin URL Web App dan tempelkan di atas.
